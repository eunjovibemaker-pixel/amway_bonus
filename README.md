# amway_bonus

암웨이 **후원수당(3%~21%)** 계산기. 빌드 없이 `index.html` 하나로 동작합니다.

## 사용법

`index.html`을 브라우저로 열면 끝입니다. (더블클릭 또는 GitHub Pages 배포)

1. 각 구성원의 **개인 그룹 PV**를 직접 입력합니다.
2. BV는 `PV × 1.78`로 자동 계산됩니다. (비율은 상단에서 변경 가능)
3. 그룹 PV에 따라 후원수당 비율이 자동으로 정해집니다.
4. `+ 다운라인` 버튼으로 하위를 원하는 만큼, 원하는 깊이까지 추가합니다.

입력값과 테마는 브라우저에 자동 저장됩니다.

## 계산식

```
BV     = 개인 그룹 PV × 1.78
총액   = BV × 본인 비율
실수령 = 총액 − Σ(직속 하위 각각의 총액)
```

실수령은 가장 아래 단계에서 먼저 확정되고 위로 올라옵니다. 상위는 본인 총액에서
직속 하위들의 총액을 뺀 **차액**만 받습니다.

## 후원수당 비율표

| 월간 구매실적 (개인 그룹 PV) | 비율 |
| --- | ---: |
| 1,000만 PV 이상 | 21% |
| 680만 PV 이상 | 18% |
| 400만 PV 이상 | 15% |
| 240만 PV 이상 | 12% |
| 120만 PV 이상 | 9% |
| 60만 PV 이상 | 6% |
| 20만 PV 이상 | 3% |
| 20만 PV 미만 | 미지급 |

## 검증

기본으로 불러오는 예시는 공식 책자의 계산 예시와 동일합니다.

- 나: 개인 그룹 PV 1,040만 → 21%
- 하위 B / C / D: 각 340만 → 12%
- PV : BV = 1 : 1 로 두면 → **실수령 960,000원** (책자 값과 일치)

`예시 불러오기` 버튼으로 언제든 이 상태로 되돌릴 수 있습니다.

## 입력 시 주의

- **개인 그룹 PV는 하위를 포함한 값**입니다. 상위 값이 직속 하위 PV 합보다 작으면 경고가 표시됩니다.
- **21%를 달성한 레그의 실적은 상위의 개인 그룹 PV에서 제외**됩니다. 하위가 21%에 도달하면 상위 PV에서 그 레그를 빼고 입력하세요.
- PV : BV 비율은 제품마다 다를 수 있고 회계연도별로 조정됩니다. 기본값 `1.78`은 PF2027 기준입니다.

## 범위 밖
