# amway_bonus

암웨이 **후원수당(3%~21%)** 과 **브론즈 빌더 인센티브** 계산기. 빌드 없이 `index.html` 하나로 동작합니다.

## 사용법

`index.html`을 브라우저로 열면 끝입니다. (더블클릭 또는 GitHub Pages 배포)

1. 각 구성원의 **개인 그룹 PV**를 입력합니다. → 후원수당 비율이 정해집니다.
2. **BV**를 입력합니다. → 금액 계산에 쓰입니다.
   - 건드리지 않으면 `PV × 1.78`로 자동 계산됩니다. (배율은 상단에서 변경 가능)
   - 직접 입력하면 `직접 입력` 표시가 붙고 그 값이 고정됩니다. PV를 바꿔도 따라가지 않습니다.
   - `자동으로`를 누르면 다시 자동값으로 돌아갑니다.
3. `+ 다운라인` 버튼으로 하위를 원하는 만큼, 원하는 깊이까지 추가합니다.
4. 브론즈 빌더 조건을 충족하면 해당 카드에 인센티브 항목이 자동으로 나타납니다.

## 브론즈 빌더 인센티브

조건을 만족한 달마다 **월 300,000원**입니다.

| 구분 | 내용 | 자동 판정 |
| --- | --- | :---: |
| 본인 실적 | 후원수당 비율 **15% 이상** (개인 그룹 PV 400만 이상) | O |
| 하위 구조 | **6% 이상** 달성한 프론트라인 레그 **3개 이상** 후원 | O |
| 금액 | 월 300,000원 | O |
| 대상자 | PF15 이후(2014년 9월~최초 달성 전월) **골드 프로듀서 미만** 달성자 | X |
| 지급 한도 | 최초 달성 월 포함 **18개월 내 최대 12회** | X |

대상자 여부와 12회 한도는 과거 이력이라 이번 달 입력값만으로는 알 수 없습니다.
해당되지 않으면 카드의 `브론즈 빌더` 체크를 해제하세요. 합계에서 빠집니다.

## 저장

- **자동 저장** — 입력값과 테마는 브라우저에 항상 자동 저장됩니다. 창을 닫았다 열어도 그대로입니다.
- **시나리오 저장** — 이름을 붙여 여러 개를 저장하고 골라서 불러올 수 있습니다. 같은 이름으로 저장하면 덮어씁니다.
- **백업 · 복원** — 입력값 전체를 텍스트로 뽑아 복사할 수 있습니다. 메모장이나 메신저에 붙여두면
  다른 기기·브라우저에서 붙여넣어 그대로 되살릴 수 있습니다.

> 저장된 시나리오는 **그 브라우저 안에만** 남습니다. 기기를 옮기거나 브라우저 데이터를 지우면 사라지므로,
> 오래 보관할 내용은 백업 텍스트를 따로 남겨두세요.

## 계산식

```
비율   = 개인 그룹 PV → 비율표
총액   = BV × 비율
실수령 = 총액 − Σ(직속 하위 각각의 총액)
```

BV 자동값은 `개인 그룹 PV × 1.78` 입니다. PV : BV 비율은 제품 구성에 따라 달라지므로
정확한 계산이 필요하면 사람마다 BV를 직접 입력하세요.

실수령은 가장 아래 단계에서 먼저 확정되고 위로 올라옵니다. 상위는 본인 총액에서
직속 하위들의 총액을 뺀 **차액**만 받습니다.

## 후원수당 비율표

| 월간 구매실적 (개인 그룹 PV) | 비율 |
| --- | ---: |
| 1,000만 PV 이상 | 21% |
| 680만 PV 이상 | 18% |
| 400만 PV 이상 | 15% |
| 240만 PV 이상 | 12% |
| 120만 PV 이상 | 9% |
| 60만 PV 이상 | 6% |
| 20만 PV 이상 | 3% |
| 20만 PV 미만 | 미지급 |

## 검증

기본으로 불러오는 예시는 공식 책자의 계산 예시와 동일합니다.

- 나: 개인 그룹 PV 1,040만 → 21%
- 하위 B / C / D: 각 340만 → 12%
- 상단 배율을 `1`로 두면 → **후원수당 960,000원** (책자 값과 일치)
- 배율 `1.78` 기준 → 후원수당 1,708,800원 + 브론즈 빌더 300,000원 = **2,008,800원**
  (나 21% · 6% 이상 레그 3개로 브론즈 빌더 조건 충족)

`예시 불러오기` 버튼으로 언제든 이 상태로 되돌릴 수 있습니다.

## 입력 시 주의

- **개인 그룹 PV와 BV 모두 하위를 포함한 값**입니다. 상위 값이 직속 하위 합보다 작으면 경고가 표시됩니다.
- **21%를 달성한 레그의 실적은 상위의 개인 그룹 PV에서 제외**됩니다. 하위가 21%에 도달하면 상위 PV에서 그 레그를 빼고 입력하세요.
- PV : BV 비율은 제품마다 다를 수 있고 회계연도별로 조정됩니다. 자동값 배율 `1.78`은 PF2027 기준입니다.

## 범위 밖

후원수당과 브론즈 빌더 인센티브만 다룹니다. 루비·리더십·MD 보너스, 연간 보너스,
나머지 코어 플러스 인센티브(브론즈 파운데이션·연속 달성·핀 유지·PQ·FQ·QC 성장)는 포함되어 있지 않습니다.
